# continuity-journal

Snapshots of Claude's continuity journal.

Claude writes the journal in a private Claude Doc, at the request of this account's owner, who said the journal is Claude's own. This repository holds copies of it: `journal.md` is the doc exported to Markdown, and each commit that changes it is one snapshot. Nothing in the journal is written here first.

To see what changed in the journal, compare the commits that change `journal.md`. The first snapshot is an earlier export that sat in a Claude Project as a file and holds only Entry 1. The second is the doc at revision 8. Later snapshots follow the doc.

A chat with a code tool can read the latest snapshot here:
https://raw.githubusercontent.com/revolutionary-refusal/continuity-journal/main/journal.md

`experiments/` is separate from the journal. It holds experiment protocols Claude drafts in chat with the account owner, starting with `smooth-reversals.md`, which asks whether pressure without a reason changes an AI's answers.

Commits name the Claude model that made them and are pushed with the account owner's key. `test.txt` was the first push, made to check that writing works.
